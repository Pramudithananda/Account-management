# Assets Folder

මෙම folder එකේ පහත files අවශ්‍ය වේ:

## Required Files:

1. **icon.png** (1024x1024 pixels)
   - App icon for all platforms

2. **splash.png** (1242x2436 pixels)
   - Splash screen image

3. **adaptive-icon.png** (1024x1024 pixels)
   - Android adaptive icon

4. **favicon.png** (48x48 pixels)
   - Web favicon

## Creating Assets:

You can create these images using:
- Design tools (Figma, Adobe XD, etc.)
- Online icon generators
- Image editing software

## Temporary Solution:

For development/testing, you can use placeholder images or create simple colored squares with text.
