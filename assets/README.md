# Assets Directory

This directory should contain the following files for a complete build:

## Required Assets

1. **icon.png** (1024x1024) - App icon
2. **adaptive-icon.png** (1024x1024) - Android adaptive icon
3. **splash.png** (1242x2436) - Splash screen image
4. **favicon.png** (48x48) - Web favicon

## Creating Assets

You can create these assets using any image editing software. For now, placeholder assets will be generated during the build process by Expo.

### Recommended Tools:
- Figma (figma.com)
- Canva (canva.com)
- Adobe Photoshop
- GIMP (free)

### Design Guidelines:
- Use a simple, recognizable icon
- Include Sinhala text if desired: "වියදම්"
- Use colors: #6366f1 (primary), #1e1b4b (dark)
- Keep design minimal and clear
