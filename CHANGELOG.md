# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-11-26

### 🎉 Initial Release

මෙම යෙදුමේ පළමු නිකුතුව / First release of the Account Management App

### ✨ Features Added

#### Multiple Account Management / බහු ගිණුම් කළමනාකරණය
- ✅ බැංකු ගිණුම් කළමනාකරණය / Bank Account Management
  - Add, edit, delete bank accounts
  - Account number tracking
  - Balance monitoring
  - Custom color coding for each account
  
- ✅ මුදල් ගිණුම් කළමනාකරණය / Cash Account Management
  - Multiple cash accounts (wallet, pocket, safe, etc.)
  - Color coding system
  - Real-time balance tracking
  
- ✅ වියදම් කාණ්ඩ / Expense Categories
  - Custom category creation
  - Target amount setting
  - Spent amount tracking
  - Progress bars with percentage
  - Over-budget warnings

#### Transaction Management / ගනුදෙනු කළමනාකරණය
- ✅ ආදායම් සහ වියදම් / Income & Expense Tracking
  - Add income transactions
  - Add expense transactions
  - Link to accounts and categories
  - Date and notes support
  
- ✅ Dashboard / මුල් පිටුව
  - Total balance overview
  - Recent transactions list
  - Quick action buttons
  - Visual summary cards

#### User Interface / පරිශීලක අතුරු මුහුණත
- ✅ Dark Mode / අඳුරු මාදිලිය
  - Toggle between dark and light themes
  - Consistent styling across all screens
  
- ✅ Sinhala Language Support / සිංහල භාෂා සහාය
  - Full UI in Sinhala
  - All labels and messages
  - Navigation titles
  
- ✅ Color Picker / වර්ණ තෝරනය
  - Preset color palette (16 colors)
  - Custom color picker
  - Visual color selection
  - Hex color code display

#### Settings & Data Management / සැකසීම් සහ දත්ත කළමනාකරණය
- ✅ Settings Screen / සැකසීම් පිටුව
  - App information
  - Dark/Light mode toggle
  - Statistics display
  
- ✅ Data Management / දත්ත කළමනාකරණය
  - Export data (backup)
  - Clear all data option
  - Local storage using AsyncStorage
  - No internet required
