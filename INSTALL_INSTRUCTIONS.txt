📲 INSTALLATION STEPS (ස්ථාපනය කිරීමේ පියවර):
--------------------------------------------

1. DOWNLOAD APK:
   - Click the link above හෝ
   - Copy link and paste in browser

2. ENABLE INSTALLATION:
   - Settings → Security → Unknown Sources → Enable
   - හෝ Settings → Apps → Special Access → Install Unknown Apps

3. INSTALL APP:
   - Open downloaded APK file
   - Click "Install" 
   - Wait for installation
   - Click "Open" to launch

================================================================================

⚠️ TROUBLESHOOTING:
------------------

Problem: "App not installed" error
Solution: 
- Enable Unknown Sources
- Clear package installer cache
- Restart phone and try again

Problem: App crashes on startup
Solution:
- Clear app data
- Reinstall the app
- Check Android version compatibility
