🔧 ක්‍රමය 2: GitHub Actions භාවිතා කිරීම

🐙 Automated Build with GitHub

GitHub repository එකක upload කර automatic APK build කරන්න

  1. GitHub repository එකක් create කරන්න
  2. Project files upload කරන්න
  3. .github/workflows/build.yml file එක add කරන්න:
    name: Build APK on: push: branches: [ main ] jobs: build: runs-on: ubuntu-latest steps: - uses: actions/checkout@v3 - name: Setup JDK uses: actions/setup-java@v3 with: java-version: '17' distribution: 'temurin' - name: Setup Node uses: actions/setup-node@v3 with: node-version: '18' - name: Install dependencies run: npm install - name: Build APK run: | cd android ./gradlew assembleDebug - name: Upload APK uses: actions/upload-artifact@v3 with: name: app-debug path: android/app/build/outputs/apk/debug/app-debug.apk
  4. Push කරාම automatic build වෙනවා
  5. Actions tab එකෙන් APK download කරගන්න
