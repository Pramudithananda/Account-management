මෙම React Native යෙදුම බහු පරිශීලක ප්‍රොෆයිල් කළමනාකරණය සහිතව

This is a complete personal finance management application built with 
React Native, featuring multi-user profile management.


🚀 ඉක්මන් ආරම්භය / Quick Start:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option 1: Automated Setup (Linux/Mac)
   ./setup.sh

Option 2: Manual Setup
   1. npm install
   2. npm start
   3. Press 'a' for Android or scan QR code

Option 3: Build APK
   1. npm install -g eas-cli
   2. eas login
   3. eas build --platform android --profile preview

✨ විශේෂාංග / Key Features:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ බහු පරිශීලක ප්‍රොෆයිල් / Multi-User Profiles
  - අසීමිත profiles සමඟ / Unlimited profiles
  - අභිරුචි avatars සහ වර්ණ / Custom avatars & colors
  - Profile-specific data isolation

✓ ගිණුම් කළමනාකරණය / Account Management
  - බැංකු ගිණුම් / Bank accounts
  - මුදල් ගිණුම් / Cash accounts
  - වර්ණ කේතනය / Color coding

✓ ගනුදෙනු ලේඛනය / Transaction Tracking
  - ආදායම් සහ වියදම් / Income & expenses
  - කාණ්ඩ අනුව / Category-based
  - දෛනික ලෙඛනය / Daily recording

✓ අයවැය කළමනාකරණය / Budget Management
  - කාණ්ඩ අනුව අයවැය / Category budgets
  - Progress tracking
  - Over-budget alerts

✓ දත්ත ආරක්ෂාව / Data Security
  - Local storage only
  - No cloud dependencies
  - Privacy-focused
