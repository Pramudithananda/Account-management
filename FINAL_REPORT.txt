APPLICATION STRUCTURE:
  ProfileProvider (Root)
    └── AppContent (Profile-aware)
        └── NavigationContainer
            ├── ProfileSelectionScreen (No profile)
            └── MainTabs (With profile)
                ├── Dashboard
                ├── Bank Accounts
                ├── Cash Accounts
                ├── Categories
                └── Settings

DATA FLOW:
  User Action
    → Context State Update
      → Auto-save to AsyncStorage
        → Profile-specific key
          → Immediate UI update

STORAGE KEYS:
  profiles                    → All user profiles
  currentProfileId           → Active profile ID
  profile_[id]_accounts      → Bank & cash accounts
  profile_[id]_transactions  → All transactions
  profile_[id]_categories    → Budget categories
  profile_[id]_darkMode      → Theme preference

BUILD METHODS CONFIGURED:

METHOD 1: EAS Build (Recommended) ⭐
  Commands:
    $ npm install -g eas-cli
    $ eas login
    $ eas build --platform android --profile preview
  
  Or use npm script:
    $ npm run build:android:preview

METHOD 2: Classic Expo Build
  Command:
    $ expo build:android -t apk

METHOD 3: Local Development
  Commands:
    $ npm install
    $ npm start
    (Then press 'a' for Android emulator)

BUILD OUTPUT:
  • APK file: sinhala-expense-tracker-vX.X.X.apk
  • Size: ~25-40 MB (optimized)
  • Min Android: 5.0 (API 21)
  • Package: com.sinhalaexpensetracker.app
